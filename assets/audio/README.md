# Audio Folder

Place all game audio files, including background music, sound effects, and ambient sounds here.

## Supported File Formats:

- **WAV**: High-quality, uncompressed audio ideal for short sound effects.
- **OGG**: Recommended for longer audio clips and background music due to small file size and good quality.
- **MP3**: Supported, but consider OGG for better looping and performance in Godot.

## Tips for Using AI Tools:

- You can upload custom audio or utilize AI tools to generate or modify sound effects and music.
- Ensure audio levels are balanced and files loop seamlessly if intended for continuous playback.
