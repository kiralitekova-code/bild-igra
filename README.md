⏳ ЭКРАН ЗАГРУЗКИ (LoadingScreen.tscn)
═══════════════════════════════════════
Красивый, информативный, с прогресс-баром:
- Фон: затемнённый арт замка с эффектом виньетки.
- По центру: анимированный логотип + **Progress Bar** (стилизован под средневековье).
- Снизу: **советы/факты** (меняются каждые 5 сек, массив из 30+ советов).
- Справа: мини-превью карты, которую загружаем.
- Случайные "строительные" анимации (подъёмный кран, кузнец кует меч).
- По завершении — плавный fade-out в игру.

Реализация:
- ResourceLoader.load_threaded_request() для асинхронной загрузки сцен.
- Отдельный поток (thread) для тяжёлых ресурсов.
- Callback на каждый % загрузки → обновление Progress Bar.

═══════════════════════════════════════
💰 ИНТЕГРАЦИЯ ЯНДЕКС РЕКЛАМЫ
═══════════════════════════════════════
Используем **Яндекс Рекламу (AdFox / РСЯ)** через JavaScript SDK.

📍 МЕСТА РАЗМЕЩЕНИЯ:
1. **Preloader (прелоадер)** — показывается пока игра грузится (3-5 сек).
2. **Sticky-баннер снизу** — во время игры, не мешает (высота 90px).
3. **Interstitial (межстраничная)** — после каждой 3-й игры / при выходе в меню.
4. **Rewarded Video (вознаграждение)** — опционально: "Посмотри рекламу = +500 золота".
5. **Баннер в меню** — статичный баннер в углу главного меню.

🔧 ТЕХНИЧЕСКАЯ РЕАЛИЗАЦИЯ:
1. В `index.html` (шаблон экспорта Godot) подключаем SDK Яндекса:
   <script src="https://yandex.ru/ads/system/context.js"></script>
2. Создаём JS-обёртку `window.AdManager` с методами:
   - showPreloader()
   - showInterstitial()
   - showRewarded()
   - showStickyBanner()
3. В Godot через **JavaScriptBridge** вызываем эти методы:
   JavaScriptBridge.get_interface("AdManager").call("showInterstitial")
4. Создаём **Autoload-скрипт AdManager.gd** — единая точка входа для рекламы.
5. Обработка событий (показ, клик, ошибка) через сигналы Godot.
6. **Кулдаун**: межстраничная не чаще 1 раза в 3 минуты (требование Яндекса).
7. **Fallback**: если реклама не загрузилась — показываем заглушку / свою "рекламу" (ссылка на соцсети).

⚠️ ВАЖНО:
- В Godot Web-экспорте реклама работает ТОЛЬКО при деплое на HTTPS-домен.
- Локально (localhost) реклама не показывается — нужна заглушка для тестов.
- Соблюдаем требования Яндекс.Рекламы: нельзя показывать рекламу во время геймплея, 
  только в меню / между играми / на загрузке.
