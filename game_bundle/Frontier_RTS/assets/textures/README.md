# Textures & Sprites Folder

Store all game images, textures, sprites, backgrounds, and UI graphics in this folder.

## Supported File Formats:

- **PNG**: Recommended for sprites, transparency, and UI elements.
- **JPEG**: Suitable for detailed backgrounds without transparency.
- **SVG**: Vector graphics for scalable UI or icons (limited support in Godot, may require import plugin).
- **WebP**: Optimized images with transparency and efficient compression.

## Tips for Using AI Tools:

- You can upload your own images or use integrated AI tools to generate images automatically.
- Ensure generated images match your project's style and dimensions.
- Consider naming files clearly for easier asset management.
