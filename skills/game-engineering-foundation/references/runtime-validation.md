# Runtime Validation

Read this file only when the shared engineering rules need runtime-specific validation notes.

## Validation surfaces

### Godot

- Read logs before concluding the task.
- Use build, runtime, and export evidence as needed.

### Web engines

- Use runtime or build evidence before concluding the task.
- Prefer screenshots when visuals or layout behavior matter.

## Screenshot fallback

- Request a screenshot from the user if screenshots would materially help and no automatic capture path exists.

## Current defaults

- Godot is the default studio-native engine path.
- Phaser is the main 2D browser-engine path.
- Three.js is the main plain web 3D path.
