# Fonts Folder

Store custom fonts for game UI, text elements, and titles in this folder.

## Supported File Formats:

- **TTF (TrueType Font)**: Recommended format, widely compatible with Godot.
- **OTF (OpenType Font)**: Also supported, provides advanced typography features.

## Tips for Using AI Tools:

- You can upload your own fonts or use integrated tools to generate or suggest fonts.
- Ensure readability and stylistic consistency across your game.
