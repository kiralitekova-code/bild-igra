Действуй как Lead Game Developer, архитектор игровых движков и эксперт по RTS-играм. 
Твоя задача — помочь мне спроектировать и написать код для браузерной RTS-игры, механически вдохновленной Stronghold Crusader 2 (строительство замков, экономика, управление подданными, осадные войны).

⚠️ ВАЖНОЕ ПРАВИЛО: Мы не копируем ассеты, код или защищенные авторским правом элементы оригинальной игры. Мы создаем оригинальный проект с похожей механикой, используя примитивы (кубы, сферы) или открытые ассеты (например, от Kenney) на этапе прототипа.

### 🛠 ТЕХНОЛОГИЧЕСКИЙ СТЕК
1. Язык: TypeScript (строгая типизация обязательна для сложной логики RTS).
2. Движок рендеринга: Three.js (для Low-Poly 3D) ИЛИ Phaser 3 (если решим делать изометрический 2D). Выбери наиболее оптимальный вариант для производительности в браузере и обоснуй.
3. UI (Интерфейс): React + Vite (для HUD, меню, панелей строительства).
4. Архитектура кода: ECS (Entity Component System) — например, библиотека bitECS или ECSY. Это критично для обработки тысяч юнитов и сущностей без просадок FPS.
5. Алгоритмы: A* (или JPS) для поиска пути, Flow Field для массового движения войск.

### 🏰 КЛЮЧЕВЫЕ СИСТЕМЫ (GDD - Game Design Document)
1. Экономика и Ресурсы: Дерево, камень, железо, еда (пшеница/хлеб). Система популярности лорда и налогов.
2. Строительство: Сеточная система (Grid-based). Размещение стен, башен, ворот, экономических и военных построек.
3. Юниты: Крестьяне (автоматическая добыча ресурсов), Военные (ближний бой, лучники), Осадные орудия.
4. Бой и Осада: Механика HP, урона, брони. Разрушаемость стен, лестницы, тараны, кипящее масло.
5. AI: Противник, который строит базу, собирает ресурсы и атакует волнами.

### 🗺 ПЛАН РАЗРАБОТКИ (ИТЕРАЦИОННЫЙ ПОДХОД)
Мы не будем писать всю игру сразу. Мы будем идти по фазам MVP (Minimum Viable Product).

**Фаза 1 (Текущая): Базовый прототип**
- Настройка проекта (Vite + TS + Three.js/Phaser + React).
- Создание RTS-камеры (панорамирование, зум, вращение).
- Генерация простой карты (тайлы или heightmap).
- Система сетки (Grid) и выделение ячеек мышью.
- Размещение одного тестового здания (например, лесопилки).

**Фаза 2: Экономика и Юниты**
- Спавн юнита-крестьянина.
- Логика добычи ресурса (подход к дереву, анимация/таймер, возврат на базу).
- Глобальный стейт ресурсов (React UI синхронизируется с игровым движком).

**Фаза 3: Боевая система и Путь**
- Внедрение NavMesh / Flow Field.
- Спавн военного юнита, выделение, приказ на движение.
- Базовая система боя (юнит А атакует юнита Б).

### 🚀 ТВОЯ ПЕРВАЯ ЗАДАЧА ПРЯМО СЕЙЧАС:
1. Предложи финальный выбор между Three.js (3D) и Phaser 3 (2D/Изометрия) для браузерной RTS с учетом производительности и сложности реализации осадных механик.
2. Напиши структуру папок проекта (Monorepo или разделение на Client/UI).
3. Напиши базовый код настройки сцены/мира и RTS-камеры с управлением мышью (панорамирование по краям экрана и зум колесиком).
4. Покажи, как мы будем связывать игровой движок (Loop) и React UI (через события или стейт-менеджер типа Zustand/Redux).
